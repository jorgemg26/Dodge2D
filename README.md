# Dodge2D

A simple 2D Android game developed in Java where the player must dodge incoming obstacles and survive as long as possible. The game focuses on reaction speed, collision detection, and increasing difficulty over time. The game and the code is in spanish

## Features

- Simple and intuitive controls
- Real-time obstacle generation
- Collision detection system
- Progressive difficulty scaling
- Score tracking based on survival time
- Game restart after defeat

## Technologies Used

- Java
- Android Studio
- Android SDK
- Object-Oriented Programming (OOP)

## Project Goals

This project was created to:

- Practice Android application development
- Apply Object-Oriented Programming concepts
- Improve game logic and collision management skills
- Learn how to structure and organize Android projects
- Gain experience in 2D game development

## Getting Started

### Prerequisites

- Android Studio
- Android SDK

### Installation

1. Clone the repository:
   ```bash:
   git clone https://github.com/your-username/Dodge2D.git
2. Open the project in Android Studio.
3. Sync Gradle dependencies.
4. Run the application on an Android device or emulator.

### Project Structure

- MainActivity – Main entry point of the application.
- GameView – Handles game rendering and updates.
- Player – Manages player behavior and movement.
- Obstacle – Handles obstacle creation and movement.
- Game Loop – Updates game state continuously.
